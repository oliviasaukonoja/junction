# Finnish Cancer Registry screening statistics, extracted 2026-11-13
Source: https://stats.cancerregistry.fi/joukkistilastot/{breast,cervix,colorectal}.html (annual statistics, 2022-2024).
Each CSV is one table; *_INDEX.tsv maps file -> section/year. Row 2 of each file is the N/% unit row.
counties_participation_2024.csv is derived (our own merge). Check quirks below before use.
Known quirks: cervix county tables appear twice per year (two sub-tables, not labelled in the extract; invited totals 280,812 and 11,298 - likely different test methods; confirm on the source page).
Southwest Finland cervical colposcopy attendance looks like a registration artifact (4 of 1,065 referred).
